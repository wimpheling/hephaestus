## Approved ownership and browser decisions

Organization is the tenant/permission boundary. Global entries are shared,
organization-owned installations. Personal ordering/pins are only preferences
within an organization. Source release and target owner must belong to the same
organization even when the actor administers both. Cross-project reuse inside
one organization remains supported. Navigation lists explicitly filter the
requested organization; actor RLS may legitimately expose both memberships.
Multiple organization tabs remain independent.

One-time handoff TTL is 60 seconds. Child sessions have a fixed maximum of 12
hours capped by parent expiry. Every request checks current parent/account,
installation generation, tenant, and permissions. No raw parent SID reaches the
UI origin. Handoff secrets are generated by Phoenix and supplied as sensitive
request inputs; child secrets use the separate host-only UI cookie. Persistence,
handoff, serving, and installed browser proofs remain unimplemented.
