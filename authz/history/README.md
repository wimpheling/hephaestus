`0006_melange_releases_and_secrets.sql` with the pinned Mélange 0.8.5 toolchain.
`scripts/check-authz-history.sh` retains its original composition, dispatcher
argument normalization, and deleted-function cleanup. Verification compares
the complete generated bytes; it never rewrites migration 0006.

`private-volumes-v1-tuples.sql` freezes the tuple input used by applied
migration0102. `scripts/generate-authz.sh` verifies its complete original bytes
and refuses to rewrite applied authorization migrations. The model is unchanged
for typed grants; migration0105 adds only their tables, integrity and projection.

The current tuple projection is the frozen0102 input plus
`authz/volume-mount-grant-tuples.sql`. `scripts/generate-volume-mount-tuples.sh`
checks both the canonical projection and its embedded0105 region. The direct
source helper is pinned to0102 model semantics and must pass native parity tests
against canonical grant/attach checks whenever authorization changes.
